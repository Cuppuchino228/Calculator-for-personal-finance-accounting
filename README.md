# Calculator-for-personal-finance-accounting
It's nothing special, a calculator is just a regular project.

1. Общая характеристика проекта

Цель проекта: разработать информационную систему на JavaScript для контроля личных доходов и расходов, обеспечивающую удобный ввод, хранение и анализ финансовых данных.

Целевая аудитория: частные пользователи, желающие систематизировать свои финансы.

Платформа: вебприложение (НTML + CSS + JavaScript) с локальным хранением данных (localStorage).

2. Функциональные требования

Система должна реализовывать следующие функции:

1. Добавление транзакций:

о ввод суммы (число);

о выбор типа: «доход» или «расход»;

о выбор категории (предустановленные: «Еда», «Транспорт», «Жильё», «Развлечения», «Здоровье», «Другие»);

о добавление даты (по умолчанию текущая);

о необязательный комментарий (строка).

2. Хранение данных:

о все транзакции сохраняются в массиве объектов;

о массив сериализуется и хранится в localStorage;

о при загрузке страницы данные восстанавливаются из хранилища.

3. Просмотр и фильтрация:

о вывод списка всех транзакций с сортировкой по дате;

о фильтрация по периоду (месяц, неделя, произвольный диапазон);

о фильтрация по типу (доходы/расходы);

о фильтрация по категории.

4. Статистика и аналитика:

о итоговая сумма доходов и расходов за выбранный период;

о баланс (доходы расходы);

о распределение расходов по категориям (в рублях и процентах);

о простой текстовый график распределения категорий (например, полоса из символов # пропорциональной длины).

5. Пользовательский интерфейс:

о форма для добавления транзакции;

о таблица со списком транзакций;

о блоки с итоговой статистикой;

о элементы управления фильтрацией;

о визуальная обратная связь (сообщения об успехах/ошибках).

3. Технические требования

Используемые структуры данных:

Массив transactions хранит все транзакции как объекты.

Объект для каждой транзакции

Объект stats для агрегированной статистики (итоги, проценты, распределение).

Технологии:

HTML - разметка интерфейса;

CSS- стилизация;

JavaScript логика приложения;

localStorage сохранение данных между сеансами.

Взаимодействие с пользователем:

Вебинтерфейс с формами, кнопками, таблицами.

Валидация ввода (проверка на число, обязательные поля).

Уведомления (например, «Транзакция добавлена», «Ошибка: сумма должна быть числом»).

4. Этапы реализации

1. Проектирование интерфейса (HTML + CSS):

о макет формы ввода;

о таблица транзакций;

о блоки статистики.

2. Базовая логика JS:

о создание массива transactions;

о функция добавления транзакции;

о рендеринг списка транзакций.

3. Хранение данных:

о сохранение в localStorage;

о загрузка при старте.

4. Фильтрация и поиск:

о функции фильтрации по дате, типу, категории;

о обновление интерфейса после фильтрации.

5. Статистика:

о подсчёт итогов;

о расчёт процентов;

о построение текстового графика.

6. Валидация и UX:

о проверка ввода;

о сообщения пользователю;

о стилизация состояний (ошибки, успехи).

7. Тестирование:

о добавление транзакций;

о проверка сохранения/загрузки;

о корректность статистики.
